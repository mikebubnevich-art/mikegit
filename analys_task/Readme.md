#  Анализ поведения пользователей мобильного приложения

##  Описание проекта

Этот проект представляет собой комплексный анализ поведения пользователей мобильного приложения финтех-компании.  
**Цель исследования** — выявить факторы, влияющие на конверсию (целевое действие), и предложить рекомендации для продуктовой команды.

Проект выполнен в формате Jupyter Notebook и включает:
- Генерацию синтетического датасета (1000 пользователей)
- Исследовательский анализ данных (EDA)
- Корреляционный анализ
- Сегментацию пользователей
- Статистическую проверку гипотез (t-test)
- Визуализацию результатов
